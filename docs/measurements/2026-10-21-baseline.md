## 2. Microbenchmark Throughput (`cargo bench`)

- **Double-buffer diff renderer (80x24 cells, 1,920 glyphs):**
  - Latency: `4.46 µs/frame`
  - Throughput: `224,142 frames/second`
  - Zero heap allocation during steady-state diff loops.
- **In-memory Save State serialization & CRC32 verification:**
  - Latency: `0.04 µs/operation`
  - Throughput: `25,340,950 operations/second`
- **Full atomic disk save I/O (temp file write + `sync_all()` + atomic `rename()`):**
  - Latency: `29.11 µs/save`
  - Throughput: `34,350 saves/second`
